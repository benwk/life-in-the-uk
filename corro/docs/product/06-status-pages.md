# 06 · 状态页

## 设计目标

**访客 5 秒内知道“是不是他们的问题、什么时候能好”。状态页本身永远打得开。**

## 托管

- 默认地址：`acme.corro.page`；可以绑定自定义域名，比如 `status.acme.com`，自动签发证书。
- **和客户的基础设施完全独立**：状态页是静态生成的，通过 CDN 分发，多个区域托管。客户的服务器全挂了，状态页照样能打开。
- 页面很轻：首屏不依赖 JavaScript 也能显示当前状态，在弱网的手机上也能秒开。
- 网页标签上的图标（favicon）跟着状态变化：正常是绿色圆点，宕机变成红色三角。

## 页面结构

```
┌─────────────────────────────────────────┐
│  [Acme Logo]                 订阅更新 🔔  │
│                                         │
│  ● 所有系统运行正常                        │  ← 第一屏，一句话结论
│    最后检查：12 秒前 · 由 9 个国家的节点确认    │
│                                         │
│  ── 进行中的事故（有的话放在最上面）──           │
│                                         │
│  API            ● ▮▮▮▮▮▮▮▮▮▮▮▮▮▮ 99.98%  │  ← 每个组件 90 天的可用率条
│  控制台           ● ▮▮▮▮▮▮▮▮▮▮▮▮▮▮ 100%    │
│  支付回调         ◆ ▮▮▮▮▮▮▮▮▮▮▮▮▯▮ 99.71%  │
│                                         │
│  ── 计划维护 ──                            │
│  ── 历史事故 ──                            │
│                                         │
│  ✓ Verified by Corro · 查看凭证            │  ← Verified 徽章
└─────────────────────────────────────────┘
```

- **组件（Components）**：客户自己定义，比如 API、控制台、支付回调。一个组件可以关联多个监控。组件可以分组。
- **可用率条**：90 天，每天一格；把鼠标放上去或者点开，能看到当天的可用率和事故。手机上显示 30 天。
- **事故更新**：由人来写（调查中 → 已定位 → 监控中 → 已解决），可以带模板。Corro 会在事故开始时自动起草第一条，值班的人确认后发布，或者设置成自动发布。
- **计划维护**：提前公告；维护期间对应监控不告警，可用率另外统计。

## 订阅

访客可以通过邮件、RSS/Atom、Webhook、Slack 订阅，可以只订阅某些组件。邮件订阅要二次确认，每封邮件都有一键退订。

## Verified by Corro

这是状态页上最有差异化的元素，见 [08 可信与验证](08-trust-and-verification.md)：

- 徽章表示：**这个页面上的可用率数字，是根据 Corro 网络中签过名的见证计算出来的，并且已经写进公开的透明日志。**
- 点开徽章，弹出一个面板：用了多少个节点、来自多少个国家、最近一次锚定时间、“自己验证”的链接和命令。
- 如果客户手动修改了某个事故的时长或者把某次故障排除在统计外，**徽章要如实显示“包含 N 处手动调整”**，并列出调整内容。手动调整是允许的（比如误配置导致的误判），但不能被隐藏。

## 多语言和无障碍

- 状态页的固定文字（“所有系统运行正常”等）支持多种语言，根据访客浏览器语言自动切换；事故更新由客户自己写。
- 支持从右往左书写的语言。
- 状态必须同时用形状、颜色和文字表达；整体对比度达到 WCAG AA。
- 默认跟随系统的浅色或深色模式。

## 客户可以定制什么

| 可以定制 | 不可以定制 |
|---|---|
| Logo、品牌主色、字体（从列表中选） | 状态颜色和形状（保证全世界的状态页一看就懂） |
| 组件、分组、显示顺序 | Verified 徽章的内容 |
| 自定义域名、页面语言 | 去掉“Powered by Corro”（付费档可以去掉） |
| 事故更新模板 | |

## 其他形式

- **嵌入组件**：一小段代码，在客户自己的网站或 App 里显示一个状态小圆点或横幅。
- **状态徽章**：给 README 用的 SVG 徽章，比如 `uptime 99.98% ✓ verified`。
- **私有状态页**（付费）：需要登录才能查看，给内部团队或大客户用。
