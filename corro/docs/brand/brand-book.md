# 品牌手册 Brand Book

> 这份手册定义 Corro “是谁、怎么说话”。视觉规范见 [设计简报](../design/design-brief.md)。

## 1. 名字

**Corro**，读作 /ˈkɒr.oʊ/（KOR-oh），两个音节，重音在前。

一个名字，三层意思：

| 来源 | 意思 | 对应产品的什么 |
|---|---|---|
| 英语 *corroborate* | 相互印证、证实 | 多节点共同确认一次故障 |
| 西班牙语、意大利语、葡萄牙语 *corro* | “我在运行”（I run） | Uptime 本身：服务在运行 |
| 西班牙语 *corro* | 围成一圈的人 | 一圈节点围着你的服务；社区网络 |

写法：

- 句中写作 **Corro**，首字母大写。
- Logo 字标用小写 **corro**。
- 不写成 CORRO、CorRo，也不加点或连字符。
- 中文环境里直接用 Corro，**不起中文名**。需要解释时说“Corro 监控”。

相关命名：

| 名字 | 用法 |
|---|---|
| Corro | 产品和公司 |
| Corro Network | 社区节点网络 |
| Corro Node | 节点程序 |
| Corro Receipt | 可验证凭证 |
| Verified by Corro | 状态页徽章 |
| CorroBot | 节点发出请求时的 User-Agent 名字 |

## 2. 定位

**一句话定位**：

> 给在线服务团队用的 uptime 监控、值班和状态页。由一张社区节点网络多方确认，记录可以独立验证。

**定位陈述**：

> 对于**被误报折磨、不想为整套可观测性平台付费**的开发者和运维团队，
> Corro 是一个**只做 uptime、值班和状态页**的产品，
> 它和其他监控工具的不同在于：**每一次故障都由不同地区、不同运营者的多个节点共同确认，每一个可用率数字都可以独立验证。**

**和竞争对手的区别**（内部参考，对外不点名比较）：

| 对比对象 | 它们 | Corro |
|---|---|---|
| Better Stack 等套件 | 把 uptime 当作可观测性平台的入口 | 只做 uptime、值班和状态页，做到最好 |
| UptimeRobot 等 | 探测点集中，单点判定，误报多 | 社区网络 + 多方确认 |
| PagerDuty、Opsgenie | 值班强，但贵或者正在退场 | 值班 + 自带监控 + 状态页，价格透明 |
| Uptime Kuma 等自托管工具 | 只有一个视角：和你的服务器在一起 | 全球多个独立视角 |
| 所有人 | 可用率由厂商自报 | 可以独立验证 |

## 3. 口号

**主口号**：**Uptime, corroborated.**

备选和场景用语：

| 用语 | 适合用在哪 |
|---|---|
| **Many eyes. One truth.** | 介绍社区网络 |
| **Only wake up for what's real.** | 介绍多方确认、告警 |
| **Don't trust us. Verify.** | 介绍 Receipt 和透明日志 |
| **Run a node. Watch the world. Get watched back.** | 招募节点运营者 |
| **I run. We watch.** | 解释名字（西语 *corro* = I run） |

中文用语（需要时使用）：

- 一圈节点，一起见证。
- 只为真实的故障醒来。
- 别信我们，自己验证。

## 4. 品牌性格

如果 Corro 是一个人，它是**你团队里那位最靠谱的 SRE**：

- 凌晨三点打电话给你时，第一句话就说清楚发生了什么，而且从不谎报军情。
- 说话有数字、有证据，不夸张，也不卖弄术语。
- 平时很安静，不刷存在感。
- 有一点温度和幽默，但从不在出事的时候开玩笑。

| 是 | 不是 |
|---|---|
| 冷静 Calm | 惊慌、制造紧迫感 |
| 精确 Precise | 含糊、夸大 |
| 诚实 Honest | 营销腔、报喜不报忧 |
| 集体 Collective | 孤胆英雄、“我们最强” |
| 开放 Open | 黑盒、“相信我们就好” |
| 温和 Warm | 冷冰冰的机器、过度可爱 |

## 5. 语气和写作规则

### 通用规则

1. **先说结论，再说细节。** “api.acme.com 宕机，已被 4 个节点确认”，而不是“我们检测到可能存在一些问题”。
2. **用数字代替形容词。** “4 个国家的 4 个节点”，而不是“多个节点”；“23 分钟”，而不是“一段时间”。
3. **说清楚确定程度。** Suspect 就说“疑似”，Corroborated 才说“确认”。不把疑似说成确认，也不把确认说成疑似。
4. **不制造恐慌。** 不用“紧急！！！”、全大写或者感叹号。严重程度由事实本身说明。
5. **不责备用户。** “无法连接到你的服务器”，而不是“你的服务器出错了”。
6. **短句。** 告警、按钮、状态文字越短越好。
7. **主动语态，直接称呼。** “你的节点今天完成了 1,204 次见证。”

### 不同场景的语气

| 场景 | 语气 | 示例 |
|---|---|---|
| 告警 | 冷静、事实、最短 | “▲ api.acme.com 宕机 · 已被 4 个国家的 4 个节点确认” |
| 恢复 | 简短、略带释然 | “● api.acme.com 已恢复 · 宕机 23 分 33 秒” |
| 疑似被否决 | 安静的报告 | “东京节点报告超时，其余 4 个节点正常，没有打扰你。” |
| 空状态 | 友好、给出下一步 | “还没有监控。输入一个网址，我们帮你看着。” |
| 节点运营者 | 感谢、有温度 | “你的节点今天帮 312 个服务确认了状态。谢谢。” |
| 营销 | 自信但不吹嘘 | “只为真实的故障醒来。” |
| 错误提示 | 诚实、给出办法 | “我们没能验证这个域名。请检查 TXT 记录是否已经生效（通常需要几分钟）。” |
| Corro 自己出问题时 | 透明、第一时间 | 在 Corro 自己的状态页公开说明，和要求客户做的一样 |

### 词汇表

| 用 | 不用 |
|---|---|
| 确认 Corroborated | 检测到、发现 |
| 疑似 Suspect | 可能宕机、警告 |
| 节点 Node | 探针、矿机、验证者 |
| 额度 Credits | 积分、代币、奖励币 |
| 可验证 Verifiable | 区块链驱动、上链、Web3 |
| 见证 Witness | 投票 |
| 运营者 Operator | 矿工、持币人 |

## 6. Logo 方向（给设计师的探索方向）

核心概念：**一圈点（节点）围成一个开口的圆，开口让它成为字母 C。**

| 方向 | 描述 | 想表达的 |
|---|---|---|
| **A · 点环 C** | 8–12 个圆点围成一个圆，右侧缺一个口，形成 C；其中 3 个点颜色更深或者有细线相连 | 节点圈 + 多方确认 + 字母 C |
| **B · 三环交汇** | 三个圆部分重叠，重叠的中心区域就是“共识”，也可以被看作一个点 | 三个独立见证的交集 = 事实 |
| **C · 字标** | 小写 **corro**，两个 r 之间做连字处理，两个 o 处理成两个节点（一实一空，或者一个带勾） | 简洁，适合开发者工具 |

要求：

- 在 16×16 的 favicon 上依然能认出来。
- 单色可用；在浅色和深色背景上都成立。
- 可以“活”起来：加载时点依次亮起，确认时连线出现。
- 有一个**状态版本**：Logo 里的某个点可以变成当前状态的颜色和形状，用在状态页的 favicon 和嵌入组件上。

## 7. 禁区

| 不要 | 原因 |
|---|---|
| 霓虹渐变、发光的立方体、链条图案、硬币 | 会让人以为这是加密货币项目 |
| 大面积的红色、警报灯、警笛图案 | 违背“冷静”；红色只留给真实的 Down |
| “作战室”式的黑底绿字、满墙仪表盘 | 太吓人，也太陈旧 |
| 卡通吉祥物、过度可爱的插画 | 值班是严肃的事；Corro 的“角色”就是那一圈点 |
| 地球仪加连线的老套“全球网络”图 | 太常见；用点阵地图和圆环代替 |
| 写实的人物照片、库存图 | 换成几何化的点和线 |
| 竞品的配色（例如 Better Stack 的风格） | 需要有自己的辨识度 |

## 8. 域名和账号

| 域名 / 账号 | 用途 |
|---|---|
| `corro.run` | 营销站；`app.corro.run` 控制台；`api.corro.run` API |
| `corro.sh` | 节点安装脚本和 CLI 文档 |
| `corro.page` | 客户的状态页（`<slug>.corro.page`）；Corro 自己的状态页是 `status.corro.run`，托管在独立的基础设施上 |
| `corro.network` | （建议注册）网络浏览器和透明日志 |
| GitHub `corro`、Docker Hub `corro/node`、npm `@corro` | 抢先注册 |

建议再注册一个带前缀的 `.com`（如 `getcorro.com`），专门用于发送邮件，提升送达率。
