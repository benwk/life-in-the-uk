# 设计简报 Design Brief

> 这份简报是给 **Claude Design**（或任何设计师）用的。产品细节见 `docs/product/`；各屏幕的设计提示词见 [screen-prompts.md](screen-prompts.md)，可以直接复制使用。

## 1. 我们在做什么

**Robin** 是一个帮助移民通过英国 **Life in the UK** 考试的 iOS 和 Android App。它的特别之处是：

1. **母语对照**：每一句话都能在英语和用户的母语之间切换，并通过“语言渐变线”帮用户逐渐过渡到只看英语。
2. **三段旅程**：学习之旅（读故事、集印章）→ 刷题之旅（每日茶歇、吹散迷雾）→ 模拟考试之旅（考场彩排）。
3. **温暖、不焦虑**：用户是压力很大的成年人。

## 2. 品牌关键词

| 是 | 不是 |
|---|---|
| 温暖 Warm | 冷冰冰的政府系统 |

| 英伦但不刻板 British, not clichéd | 满屏米字旗、红色电话亭、大本钟 |
| 平静自信 Calm confidence | 倒计时焦虑、红色警告 |

| 精致的手作感 Crafted | 廉价的卡通、过度游戏化 |

**一句话的感觉**：*像一本精心设计的旅行手账，有一只友好的知更鸟陪你翻页。*

## 3. 核心视觉隐喻

| 元素 | 灵感来源 | 用在哪里 |
|---|---|---|
| 🚆 **铁路线路图** | 彩色线路、圆点车站、换乘站（**自己画，不用 TfL 的样式和圆环标志**） | 学习之旅主页、迷雾地图 |
| 🛂 **护照印章** | 老式入境章、邮戳：圆形或椭圆边框、日期、略微不均匀的墨色和旋转角度 | 成就、进度、分享卡片 |
| ☕ **茶和茶杯** | 下午茶、马克杯、骨瓷 | 每日茶歇、连续天数 |
| 🌫️ **迷雾** | 英国的雾：柔和、半透明 | 遗忘和复习提醒 |
| 🐦 **知更鸟 Robin** | 红胸知更鸟：圆滚滚、橙红色胸口 | 吉祥物、空状态、反馈 |
| 📮 **邮筒红、赛车绿** | 英国街头的经典颜色 | 配色参考 |

## 4. 配色方向（建议，欢迎推翻）

基调：**奶油纸张 + 墨水深蓝**，用几种“英国街头色”作为强调色，5 条线路各一个颜色。

| Token | 建议色值 | 用途 |
|---|---|---|
| `paper` | `#FAF6EE` | 背景（浅色模式） |
| `ink` | `#1F2A44` | 主要文字 |
| `robin` | `#E4572E` | 品牌强调色、Robin 的胸口、主按钮 |
| `pillar-red` | `#C8102E` | 谨慎使用，只用于印章 |
| `racing-green` | `#1E4D3A` | 正确、掌握 |
| `amber` | `#F2A541` | 答错（温和，**不用红色**） |
| `fog` | `#C9CED6` 半透明 | 迷雾效果 |
| `line-values` | `#6C4AB6` 紫 | 线路 1：价值观与原则 |
| `line-uk` | `#2E86AB` 蓝 | 线路 2：什么是英国 |
| `line-history` | `#B5651D` 棕 | 线路 3：悠久的历史 |
| `line-society` | `#2A9D8F` 青 | 线路 4：现代社会 |
| `line-government` | `#264653` 墨绿 | 线路 5：政府、法律与你 |

- **深色模式**：背景用深墨蓝 `#141A2A`，纸张质感变成“夜间车厢”的感觉；线路颜色提亮。
- **考场模式**：去掉所有品牌色，白底黑字加一个中性蓝，像真实考场的电脑界面。
- 所有文字和背景的对比度达到 WCAG AA。

## 5. 字体

必须支持多种文字系统，所以选 **Noto** 家族作为基础，保证拉丁、CJK、阿拉伯、天城文等风格统一：

| 用途 | 字体建议 |
|---|---|
| 标题（拉丁） | 一款有英伦气质的衬线字体，例如 **Fraunces** 或 **Source Serif** |
| 正文（拉丁） | **Inter** 或系统字体（SF Pro、Roboto） |
| 中文 | 苹方、思源黑体 / Noto Sans SC、TC |
| 阿拉伯语、波斯语 | Noto Naskh Arabic |
| 乌尔都语 | Noto Nastaliq Urdu（行高要额外留空间） |
| 印地语、孟加拉语、旁遮普语 | Noto Sans Devanagari、Bengali、Gurmukhi |
| 年份和数字 | 标题衬线字体的等宽数字，用于时间线和大号年份 |

**避免**：GOV.UK 的 Transport 字体和政府的视觉风格。我们不能看起来像官方 App。

## 6. 插画风格

- **扁平 + 纸张质感**：轻微的纸纹、略带手绘感的线条，像旅行手账里的贴纸。
- 人物插画要**多元**：不同肤色、年龄、宗教服饰（头巾、头巾帽）。
- 历史场景用简化的剪影式插画，不追求写实。
- Robin 的形象：圆滚滚的身体、橙红色胸口、大眼睛、小短腿；**可爱但不幼稚**，成年人用着不尴尬。

## 7. 动效

| 场景 | 动效 |
|---|---|
| 盖章 | 印章从上方落下，轻微回弹，墨迹晕开 |
| 答对 | 选项变绿 + Robin 小跳 |
| 答错 | 选项温和地变成琥珀色，Robin 歪头 |
| 吹散迷雾 | Robin 扇翅膀，雾从中间散开 |
| 点句翻转 | 卡片沿 Y 轴翻面 |
| 线路图 | Robin 沿线路飞到下一站 |

所有动效都要支持系统的“减少动态效果”设置。

## 8. 关键设计挑战（请重点探索）

1. **双语卡片**：英语 + 母语同时出现时，怎样层次清晰、不拥挤？尤其是**英语（从左往右）+ 乌尔都语（从右往左）**在同一张卡片里。
2. **线路图**：在手机竖屏上怎样既好看又好点？20 多个车站怎么排布？
3. **答题页**：在“有趣”和“像真考”之间找平衡：练习模式可以有 Robin 和色彩；考场模式要干净、中性。
4. **护照印章**：一套近 30 枚印章（24 个车站章 + 5 个线路大章）的视觉系统，每枚有一个小图标，但整体统一。
5. **大字号和 RTL**：200% 字号和镜像布局下依然好看。
