# 03 · 体验全景：三段旅程

## 核心隐喻：一次穿越英国的旅行

整个 App 是一趟**火车旅行**。Robin（知更鸟吉祥物）是你的旅伴。

- 官方手册的 5 个章节是 5 条**线路**，每条线路有自己的颜色。
- 每个小节是线路上的一个**车站**。
- 每到一站，读几张**故事卡**，在**护照**上盖一个印章。
- 没掌握牢的车站会被**雾**笼罩；刷题就是把雾吹散。
- 终点站是 **Test Day（考试日）**。

> 设计参考的是“铁路线路图”这种视觉语言：彩色线路、圆点车站、换乘站。**不要**直接使用伦敦地铁的圆环标志或 TfL 的线路图样式，它们受商标和版权保护。我们要画自己的线路图。

```
 线路图（示意）

 ● 价值观与原则 ──●──●──◉ 换乘
                          │
 ● 什么是英国 ─────●──●───◉
                          │
 ● 悠久的历史 ──●──●──●──●──●──●──◉      ← 最长的一条线，时间线
                          │
 ● 现代社会 ────●──●──●──●──●──●──◉
                          │
 ● 政府、法律与你 ──●──●──●──●──●──◉
                          │
                          ▼
                    🎫 TEST DAY 终点站
```

## 三段旅程

| | 🗺️ 学习之旅 The Journey | ☕ 刷题之旅 Tea Break | 🎫 模拟考试之旅 Test Day |
|---|---|---|---|
| **一句话** | 用母语读懂英国的故事 | 每天一杯茶的时间，把知识刻进记忆 | 在真实考场的节奏里证明自己准备好了 |
| **核心动作** | 读故事卡 → 小测 → 盖印章 | 答题 → 即时反馈 → 间隔重复 | 24 题 / 45 分钟 → 成绩单 → 错题复盘 |
| **语言支持** | 母语优先，可一键切换对照 | 英文为主，随时点开翻译 | 真考模式全英文；练习模式可以用“求助卡” |
| **乐趣机制** | 护照印章、地图点亮、Robin 讲故事 | 吹散迷雾、连胜茶杯、小游戏题型 | 准备度仪表、通过预测、“考场彩排” |
| **时长** | 每站 3–5 分钟 | 每轮 5 题，约 3 分钟 | 完整模考 ≤ 45 分钟；迷你模考 10 分钟 |
| **详细设计** | [04 学习之旅](04-learning-journey.md) | [05 刷题之旅](05-practice-journey.md) | [06 模拟考试之旅](06-mock-exam-journey.md) |

三段旅程不是线性关卡，而是**可以随时切换**的三种模式。但 App 会推荐一条节奏：

```
   学一站 ──► 刷这站的题 ──► 解锁下一站
     ▲                           │
     │        每天：☕ 茶歇（混合复习）
     │                           │
     └──── 雾出现（遗忘）◄───────┘

   全部线路走完 + 准备度 ≥ 80% ──► 推荐完整模考
```

## 贯穿三段旅程的“语言渐变线”

这是 Robin 最有辨识度的设计。

```
 母语为主 ───────────────────────────────────► 英语为主

 学习之旅          刷题之旅                 模拟考试之旅
 [母语 + 英语]     [英语 + 点开看母语]       [只有英语]
 📖 读懂           🧠 记住                  ✍️ 答对
```

- 每个知识点和每道题都有**英语原文 + 母语对照**。
- App 根据用户的掌握度，**逐渐减少默认显示的母语**。用户随时可以手动调回来，而且绝不惩罚。
- 详细规则见 [07 语言体验](07-language-experience.md)。

## 信息架构（底部导航）

| Tab | 名字 | 内容 |
|---|---|---|
| 1 | **今日 Today** | Robin 的问候、今日茶歇（5 题）、继续上次的车站、“英国历史上的今天”、准备度 |
| 2 | **旅程 Journey** | 线路图（学习之旅入口）、车站详情、故事卡 |
| 3 | **练习 Practice** | 按线路或车站练习、错题本、收藏、小游戏题型、迷雾地图 |
| 4 | **考场 Test Day** | 准备度仪表、完整模考、迷你模考、历史成绩、考前清单 |
| 5 | **护照 Passport** | 印章收藏、连续学习、语言设置、词汇本、个人设置 |

## 首次打开（Onboarding）

目标：**60 秒内**让用户感到“这个 App 懂我”。

1. **选择语言**：国旗 + 语言原名（“中文（简体）”“繁體中文”“Українська”“اردو”…），**不写成英文**。
2. **Robin 打招呼**：用用户选择的语言说“欢迎！我陪你走完这段旅程。”
3. **你打算什么时候考？** 已预约（选日期）/ 大概 1 个月内 / 还没想好。用来安排学习计划。
4. **你的英语阅读感觉怎么样？** 三档，决定语言渐变线的起点：
   - “我需要母语帮忙” → 母语优先
   - “能看懂大部分” → 双语对照
   - “英语没问题” → 英语优先，翻译随时可点
5. **每天能学多久？** 5 / 10 / 20 分钟。
6. **（可选）快速摸底**：6 道题，Robin 据此在线路图上标出“你已经熟悉的车站”。
7. 进入线路图，第一站亮起，Robin 飞过去：“我们从这里出发。”

## 关键时刻（Moments that matter）

| 时刻 | 设计意图 |
|---|---|
| 第一次盖印章 | 印章“啪”地落下，伴随轻微震动；Robin 欢呼。让人想集齐。 |
| 第一次答错 | Robin 不说“错了”，而说“这题很多人都会错，我们看看为什么”，然后给出母语解析。 |
| 连续学习 7 天 | 解锁一个新的茶杯款式（见 [08 乐趣与动力](08-fun-and-motivation.md)）。 |
| 某站起雾了 | 线路图上这一站变灰，Robin 提醒：“这里有点雾了，花 2 分钟吹散它？” |
| 第一次完整模考通过 | 全屏庆祝，给出“你已经准备好了”的确认，以及考前清单入口。 |
| 考试前一天 | 推送温柔提醒：带好证件、提前到场、今晚早点睡。**不再推题。** |
| 真考之后 | 问一句：“考得怎么样？”通过了就颁发“毕业护照”，可分享；没通过就给出安慰和重新计划。 |
