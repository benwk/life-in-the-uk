# 04 · 学习之旅 The Journey

> 目标：**用母语读懂，用故事记住。** 把 180 页的手册变成 24 个车站、每站 3–5 分钟的小故事。

## 结构

```
线路 Line（手册章节，5 条）
 └─ 车站 Station（手册小节，共 24 个）
     └─ 故事卡 Story Card（每站 5–10 张）
         └─ 知识点 Fact（最小学习和复习单位）
```

- **知识点（Fact）** 是整个系统的原子：故事卡由它组成，题目由它生成，间隔重复按它排期，掌握度也按它统计。
- 车站列表见 `content/journey/lines.json`，数据格式见 [内容模型](../tech/content-model.md)。

## 线路图页面

- 5 条彩色线路；车站有 4 种状态：
  - 🔒 **未到达**：灰色空心圆
  - 🔵 **可以出发**：线路颜色的空心圆，轻微呼吸动画
  - ✅ **已盖章**：实心圆 + 小印章图标
  - 🌫️ **起雾**：已盖章但掌握度下降，车站被半透明雾气覆盖
- Robin 停在“下一站”上方。
- 线路之间有**换乘站**，比如“都铎王朝”站可以换乘到“宗教”站。用户可以按兴趣跳线，不强制顺序。
- 地图可以缩放；缩到最小是整个英国的轮廓，车站分布在真实地理位置附近（能对上的话），比如“苏格兰”站在北边。

## 车站页面

1. **封面**：一幅插画 + 车站名（英语 + 母语）+ “约 4 分钟”+ 本站要收集的印章。
2. **故事卡**：左右滑动，一张卡讲一件事。
3. **站台小测**：3 道题，答对 2 道就能盖章。
4. **盖章**：印章落在护照上，线路图更新。

## 故事卡：怎么让它有趣

每张故事卡**只讲一件事**，并且是**有画面的一件事**。卡片类型：

| 类型 | 示例 | 设计要点 |
|---|---|---|
| 📜 **故事** | “1215 年，贵族们逼约翰国王在一份文件上盖章……” | 有人物、有冲突、有结果；3–4 句话 |
| 📅 **时间点** | 1066 · 黑斯廷斯战役 | 大号年份 + 一句话 + 小插画；自动加入“时间轴收藏” |
| 👤 **人物** | 伊丽莎白一世 | 头像插画、一句话身份、一个记忆钩子 |
| 🗺️ **地图** | 英国四个组成部分 | 可点击的地图，点哪里讲哪里 |
| ⚖️ **对比** | 大不列颠 vs 联合王国 vs 不列颠群岛 | 维恩图或并排卡片，专门拆易混概念 |
| 🔢 **数字** | 议会有 650 个选区 | 数字大号显示，配一个生活化的对比 |
| 💡 **记忆钩子** | “圣大卫日 3 月 1 日：威尔士人戴水仙（Daffodil 也是 D 开头）” | 用用户的母语写，允许谐音、联想、口诀 |
| ⚠️ **考试提醒** | “手册里写的是女王，考试以手册为准” | 标注手册与现实的差异，以及常见陷阱 |

### 故事卡的语言显示

- 默认按用户的语言渐变阶段显示（见 [07 语言体验](07-language-experience.md)）。
- **点一下句子**：在英语和母语之间翻转（卡片翻面动画）。
- **长按一个英文单词**：弹出词汇卡（母语释义、发音、所在句子）。
- **🔊 朗读**：先读英语，再读母语（可在设置里改成只读英语）。
- 关键术语（如 *Parliament*）在英文里**加下划虚线**，表示可以点开看解释，并自动收进词汇本。

### 记忆钩子：母语的魔法

记忆钩子是**按语言单独创作的**，不是翻译出来的。同一个知识点：

- 中文：“**1066**，要溜溜溜：威廉公爵一溜烟打过来了。”
- 其他语言由对应语言的内容编辑写各自的谐音或联想。

没有母语钩子的语言，显示英文钩子（比如英语押韵或首字母缩写）。

## 专题收藏：学习之外的“地图册”

盖过章的内容会自动整理进几个可以随时翻阅的专题：

- 🕰️ **时间轴**：所有年份按顺序排开，可以横向拖动。“1066 → 1215 → 1348 → …”
- 👑 **君主家谱**：从盎格鲁-撒克逊到今天，点头像看小故事。
- 🧑‍🎨 **名人堂**：科学家、作家、运动员、发明家，按领域分类。
- 🏴 **四个国家**：英格兰、苏格兰、威尔士、北爱尔兰的守护圣徒、节日、首府、国花。
- 🏛️ **议会与法律**：一张结构图讲清楚下议院、上议院、君主、法院的关系。

这些专题页都是**高价值的复习工具**，也很适合截图分享到同乡群里。

## 护照印章

- 每个车站一枚印章，每条线路走完得一枚“线路大章”。
- 印章设计成老式邮戳或入境章风格：圆形或椭圆边框、日期、车站名、小图案（例如“中世纪”站是一顶骑士头盔）。
- 盖章的日期是**用户真实学习的日期**，让护照成为一份个人纪念。
- 印章起雾时颜色会变淡，吹散迷雾后恢复。

## 边界情况

- **用户跳着学**：允许。未到达的车站只是提示“建议先完成前面的车站”，不锁死。
- **内容更新**：手册如果改版，受影响的车站显示“新内容”标记；已经盖的章保留。
- **没有这个语言的翻译**：显示英语 + 机翻兜底，并标注“机器翻译，仅供参考”，同时邀请社区志愿者改进。
