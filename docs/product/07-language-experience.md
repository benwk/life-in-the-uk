# 07 · 语言体验：母语是桥，英语是岸

> 这是 Robin 和其他备考 App 最大的区别。翻译不是一个开关，而是一整套**帮用户从母语走向英语**的体验。

## 三种显示模式

用户在任何页面都能通过右上角的 **🌐 语言透镜 Language Lens** 快速切换：

| 模式 | 显示 | 适合 |
|---|---|---|
| **母语优先** | 母语大字在上，英语小字在下 | 刚开始，看英语很吃力 |
| **双语对照** | 英语大字在上，母语小字在下 | 大部分用户的默认模式 |
| **英语优先** | 只显示英语，点一下句子才显示母语 | 冲刺阶段、英语较好的用户 |

```
 母语优先                 双语对照                 英语优先
┌──────────────────┐   ┌──────────────────┐   ┌──────────────────┐
│ 1215 年，约翰国王 │   │ In 1215, King    │   │ In 1215, King    │
│ 被迫同意《大宪章》│   │ John was forced  │   │ John was forced  │
│                  │   │ to agree to the  │   │ to agree to the  │
│ In 1215, King    │   │ Magna Carta.     │   │ Magna Carta.     │

```

## 语言渐变线 English Gradient

App **自动**帮用户一步步减少对母语的依赖，但永远不强迫。

- 每个用户有一个“英语自信度”指标，由这些行为估算：
  - 在英语优先模式下答对的比例
  - 点开翻译的频率（越来越少是好信号）
  - 查词频率
  - 在英语模式下的阅读速度
- 自信度达到阈值时，Robin 会问：“最近你很少看翻译了，要不要试试**双语对照**模式？”**用户同意才切换。**
- 在车站和题目层面也会细调：用户已经牢牢掌握的知识点，默认用英语显示；新知识点仍然用母语辅助。
- 模拟考试的“考场模式”是渐变线的终点：全英文。

> 设计原则：**永远可以退回去，而且不丢面子。** 切回母语优先时，不显示任何“退步”之类的提示。

## 点句翻转、长按查词

- **点一下句子**：卡片翻面，在英语和母语之间切换，就像翻一张单词卡。
- **长按一个英文单词**：弹出**词汇卡**
  - 单词 + 音标 + 🔊 发音
  - 母语释义（**是在这个语境里**的意思，不是词典里的第一个义项）
  - 简单英语释义（帮助过渡）
  - “收进词汇本”按钮
- 关键术语在英文里用**下划虚线**标出，暗示可以点开。

## 词汇本 Word Bank

- 自动收录：用户查过的词 + 学过的车站里的关键术语。
- 按车站分组，也可以按字母排序。
- 词汇本里的词也进入间隔重复，出现在每日茶歇里，形式是“看英语选母语意思”或反过来。
- 这让 Robin 顺便成为一个**英语词汇学习工具**，这对 Olena 这样的用户尤其有价值。

## 陷阱雷达 Trap Radar

很多丢分不是因为不懂知识，而是没读懂题目。陷阱雷达会在题干中高亮：

| 关键词 | 提示（母语） |
|---|---|
| **NOT** / **isn't** | “注意：问的是哪个**不是**” |
| **TWO** | “要选**两个**答案” |
| **always** / **never** / **only** | “绝对化的词，想想有没有例外” |
| **true** / **false** | “判断题” |
| **Which of these statements is correct?** | “两句话里只有一句是对的” |

可以在设置里关掉。模拟考试的考场模式里**默认关闭**（真考里没有这个）。

## 朗读 Listen Mode

- 所有故事卡和题目都能朗读，适合通勤和视力不好的用户。
- 先用系统自带的 TTS（iOS 用 AVSpeechSynthesizer，Android 用 TextToSpeech），不需要额外的音频文件，App 包也不会变大。
- **听书模式**：把一整个车站的故事卡连成一段音频，锁屏后也能继续播放（英语一遍，母语一遍）。
- 朗读速度可以调节：0.75× / 1× / 1.25×。

## 支持哪些语言

按英国主要移民来源和考生需求排序：

| 阶段 | 语言 | 备注 |
|---|---|---|
| **MVP** | English、简体中文、繁體中文 | 繁中面向香港 BNO 群体，不只是简繁转换，用词也要本地化（例如“的士”“巴士”） |
| **第二批** | اردو 乌尔都语、العربية 阿拉伯语、हिन्दी 印地语、Українська 乌克兰语 | 包含两种 RTL 语言，验证镜像布局 |
| **第三批** | বাংলা 孟加拉语、ਪੰਜਾਬੀ 旁遮普语、Polski 波兰语、Română 罗马尼亚语、فارسی 波斯语、Español、Português、Tiếng Việt 越南语 | 按用户需求调整顺序 |

### 翻译质量分级

每条翻译带一个质量标签，界面上用很小的图标显示：

- ✅ **人工审校**：母语审校员确认过
- 🤖 **机器翻译**：大模型翻译、尚未审校，显示“仅供参考”
- 👥 **社区贡献**：用户提交了修改建议，待审校

用户可以在任何翻译上长按 → “建议更好的翻译”。

## 界面语言 vs 学习语言

- **界面语言**（按钮、菜单）：默认跟随系统，可以单独设置。
- **学习辅助语言**（对照翻译、解析、记忆钩子）：用户在首次打开时选择。
- 两者可以不同。例如在英国出生的第二代帮父母设置：界面用英语，学习辅助用乌尔都语。

## RTL（从右往左）语言

- 整个布局镜像：返回箭头、进度条方向、滑动方向。
- **双语对照时**，英语段落保持从左往右，乌尔都语或阿拉伯语段落从右往左，两者在同一张卡片里各自对齐。
- 数字和年份保持西方阿拉伯数字（1066），与考试一致。
- 字体：阿拉伯语和波斯语用 Noto Naskh Arabic；乌尔都语用 Noto Nastaliq Urdu（行高要额外留空间）。

## 可访问性

- 支持系统字号设置（Dynamic Type 或 Android 字体缩放），最大到 200% 不能破版。
- 额外的**大字号模式**开关。
- 对比度达到 WCAG AA。
- 所有图标都有文字标签；屏幕阅读器（VoiceOver、TalkBack）能完整操作。
- 颜色不是唯一的信息来源：答对、答错同时使用颜色 + 图标 + 文字。
