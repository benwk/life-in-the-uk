# 06 · 模拟考试之旅 Test Day

> 目标：**把“我觉得我会了”变成“我知道我能过”。** 在和真考一模一样的环境里彩排，考前心里有底。

## 真实考试的规则（模考必须一致）

| 项目 | 规则 |
|---|---|
| 题目数 | 24 题 |
| 时长 | 45 分钟 |
| 及格线 | 答对 18 题（75%） |
| 语言 | 英语（苏格兰盖尔语、威尔士语考生另有安排，不在本 App 范围） |
| 题型 | 单选、判断、双选、哪句正确 |
| 答题方式 | 可以标记、跳过、回头修改，最后统一提交 |

> 这些规则写在内容包的 `meta.exam` 里（`content/meta.json`），App 从这里读取，两端不写死。政府如果调整规则，只改一处。

## 准备度仪表 Readiness

“考场”页最上方是一个**准备度仪表**，回答 Arjun 最关心的问题：“我现在去考能过吗？”

- 数值 0–100%，基于：
  - 各线路知识点的掌握度（按真考中各章节的大致出题比例加权）
  - 最近 3 次模考成绩
  - 最近答错率
- 三个区间：
  - 🔴 **还在路上**（< 60%）：“再走几站吧”
  - 🟡 **快到了**（60–80%）：“再做两次模考看看”
  - 🟢 **准备好了**（> 80% 且最近 3 次模考都 ≥ 21/24）：“可以去预约考试了！”
- 仪表下方列出**最薄弱的 3 个车站**，一键进入练习。

> ⚠️ 准备度只是估计，不是保证。界面上要写明这一点，避免用户过度依赖。

## 模考模式

### 🎫 完整模考 Full Mock

- 24 题，45 分钟，出题比例模拟真考的章节分布。
- **考场模式**：
  - 界面切换成简洁、中性的“考场皮肤”（接近真考的电脑界面风格：白底、清晰字体、题号导航）。
  - Robin 和所有游戏化元素**隐藏**。
  - **不显示翻译**，也不能查词。这是在为真考彩排。
  - 可以标记题目、在题号面板跳转。
  - 倒计时显示在角落，**不闪红**；剩 5 分钟时温和提示一次。
- 提交后出**成绩单**。

### ⏱️ 迷你模考 Mini Mock

- 8 题，15 分钟。没有大块时间时用。
- 同样是考场模式，但不计入准备度的“最近 3 次模考”。

### 🛟 辅助模考 Assisted Mock

- 给语言还在过渡期的用户。
- 规则和完整模考一样，但有 **3 张“求助卡”**：每张可以看一道题的母语翻译。
- 成绩单上会标注“使用了 X 张求助卡”。这不是惩罚，而是让用户清楚自己离真考还差多少。
- 连续两次不用求助卡就通过时，Robin 建议：“下次试试完整模考？”

## 成绩单

- 大号分数：**20 / 24 · 通过 ✅**，或 **16 / 24 · 还差 2 题**。
- 用时。
- **按线路拆分**：哪条线路丢分最多（条形图）。
- **错题复盘**：逐题显示“你的答案 / 正确答案 / 母语解析 / 回到故事卡”。复盘时翻译**重新可用**。
- 历史成绩折线图：最近 10 次模考。
- 一键“把错题加入今日茶歇”。

## 考前清单 Test Day Checklist

当用户设置了考试日期，“考场”页会出现倒计时卡片和清单：

- [ ] 在 GOV.UK 官方网站预约（App 提供官方链接，**不提供**第三方代订）
- [ ] 确认考点地址和交通
- [ ] 准备**预约时使用的同一份身份证件**
- [ ] 提前到达考点
- [ ] 前一晚：早点睡，不要熬夜刷题

> 清单内容以 GOV.UK 官方说明为准，App 里的文字要标注“请以官方页面为准”，并链接到 https://www.gov.uk/life-in-the-uk-test。

**考前 3 天**：App 自动切换成“轻复习”模式，只推错题和易混对比，不再推新内容。

**考试当天**：打开 App 只显示一张卡：“今天加油！你已经准备好了。”加上考点地址和清单，不推题。

## 考后

- 第二天推送（可关闭）：“考得怎么样？”
  - **通过了**：颁发**毕业护照**：一张可以分享的纪念卡，印着所有盖过的章、学习天数、模考最高分。Robin 戴上学士帽。
  - **没通过**：“没关系，很多人第二次就过了。”根据用户回忆的薄弱部分重新规划 7 天计划。**不说任何让人更难过的话。**
  - **不想说**：尊重。
