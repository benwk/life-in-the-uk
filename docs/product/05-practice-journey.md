# 05 · 刷题之旅 Tea Break

> 目标：**把“读懂”变成“记住”，把“记住”变成“答对”。** 每天一杯茶的时间，不枯燥、不焦虑。

## 核心：每日茶歇 ☕

- 每天 5 道题，约 3 分钟，是 App 最重要的日常入口，放在“今日”页最上方。
- 题目由**间隔重复算法**挑选：
  - 60%：到期该复习的知识点（快要遗忘的）
  - 25%：最近答错的知识点
  - 15%：刚学过、还没练过的新知识点
- 完成后，茶杯被“喝完”，连续天数 +1。
- 想多做可以“再来一杯”，没有上限，但 Robin 会在 30 题左右温柔提醒休息。

### 间隔重复

- 排期单位是**知识点**而不是题目。同一知识点有多道不同问法的题，每次复习换一种问法，避免“背答案”。
- 算法用 **FSRS**（开源的新一代间隔重复算法，比 SM-2 更准），参数先用默认值，积累数据后再调。
- 每个知识点的掌握度分 4 级，在车站和线路上汇总显示：

| 等级 | 名字 | 线路图上的表现 |
|---|---|---|
| 0 | 未学 | 灰色 |
| 1 | 眼熟 | 浅色 |
| 2 | 记住了 | 线路色 |
| 3 | 牢牢掌握 | 线路色 + 金边 |

- 掌握度下降（快遗忘）时，车站起雾 🌫️。

## 迷雾地图 🌫️

这是刷题之旅的核心视觉：

- “练习”页顶部是同一张线路图，但显示的是**记忆状态**而不是学习进度。
- 起雾的车站越多，说明遗忘越多。
- 点一个起雾的车站 → 做 3–5 道这个车站的题 → 雾被 Robin 扇动翅膀吹散（动画）。
- 用户一眼就知道“我该复习哪里”，比一堆百分比直观得多。

## 题型

### 考试题型（和真考一致，模拟考试也用这些）

| 题型 | 说明 | 设计要点 |
|---|---|---|
| **单选** | 4 个选项选 1 个 | 最常见 |
| **判断** | True / False | 大按钮；题干中的否定词高亮 |
| **双选** | 4 个选项选 2 个 | 顶部显眼提示“选 **两个** 答案”，选够两个才能提交 |
| **哪句正确** | 两个陈述句选正确的一个 | 两张卡片上下排列，容易比较 |

### 练习专属的小游戏题型（让刷题有乐趣）

这些题型**只在练习中出现**，从另一个角度巩固同一批知识点：

| 小游戏 | 玩法 | 适合的知识 |
|---|---|---|
| 🕰️ **时光排序 Time Traveller** | 把 4 个历史事件拖到时间线上排好顺序 | 年份、朝代 |
| 🔗 **连连看 Match Up** | 左边圣徒、右边国家，连线配对 | 守护圣徒、节日、首府、国花 |
| 🃏 **快问快答 Quick Fire** | 60 秒内判断尽可能多的对错，左右滑动 | 判断题知识点 |
| 🧩 **找不同 Odd One Out** | 4 个里挑出不属于同一类的 | 人物分类、机构分类 |
| 🗺️ **地图点点 Pin It** | 在英国地图上点出某个地方的位置 | 地理、景点 |
| 🍺 **酒馆问答 Pub Quiz** | 一台手机，2–4 个人轮流答题 | 家人、同乡一起备考 |

## 答题反馈

- **答对**：选项变绿，轻微震动，Robin 小跳一下。只显示一行英文解析，可以展开母语。
- **答错**：
  1. 不用刺眼的红色大叉，而是**温和的橙色**标出用户的选择，绿色标出正确答案。
  2. 自动展开**母语解析**：为什么对，为什么错。
  3. 如果错因是**题干理解**（比如没看到 NOT），专门提示：“这题问的是哪个**不是**，再看一眼题干？”
  4. 提供“📖 回到故事卡”链接，直接跳到对应知识点。
  5. 自动加入错题本。

### 题干语言工具

每道题底部有一个小工具栏：

- 🌐 **翻译**：显示整道题的母语翻译（学习、练习模式可用）
- 🔍 **查词**：长按任何单词
- 🔊 **朗读**：朗读题干和选项
- ⚠️ **陷阱雷达**：自动高亮 *NOT*、*TWO*、*always*、*only* 等关键词，用户可以关掉

使用翻译**不扣分、不影响掌握度**，但会被记录下来，用于判断语言渐变的进度（见 [07 语言体验](07-language-experience.md)）。

## 错题本和收藏

- **错题本**：按车站分组；答对 2 次后自动“毕业”移出，也可以手动移出。
- **收藏**：用户觉得重要的题。
- **易混对比**：系统发现用户经常把两个知识点搞混（比如 St Andrew 和 St David 的节日日期），自动生成一张对比卡。

## 练习入口一览
