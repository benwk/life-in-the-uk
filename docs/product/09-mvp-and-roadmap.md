# 09 · MVP 范围与路线图

## MVP（v0.1）：先证明“语言对照 + 三段旅程”成立

**目标用户**：简中和繁中用户（数量多，而且我们自己能审校翻译）。

| 模块 | MVP 包含 | 以后再做 |
|---|---|---|
| **内容** | 5 条线路、全部车站、约 400 个知识点、约 800 道原创题；英语 + 简中 + 繁中 | 更多语言、插画版故事卡 |
| **首次打开** | 选语言、考试时间、英语水平、每日时长 | 摸底测试 |
| **学习之旅** | 线路图、车站、故事卡（故事、时间点、对比、考试提醒）、站台小测、护照印章 | 地图卡、专题收藏（时间轴、君主家谱） |
| **刷题之旅** | 每日茶歇、间隔重复（FSRS）、4 种考试题型、答题反馈、错题本 | 小游戏题型、迷雾地图动画、酒馆问答 |
| **模拟考试** | 完整模考、成绩单、错题复盘、准备度（简化版） | 迷你模考、辅助模考、考前清单 |
| **语言体验** | 三种显示模式、点句翻转、朗读（系统 TTS） | 长按查词、词汇本、陷阱雷达、语言渐变自动建议 |
| **乐趣** | Robin 静态插画 + 几种表情、印章、连续天数 | Robin 动画、茶杯收藏、隐藏印章、分享卡片 |
| **平台** | iOS 17+（SwiftUI）、Android 8+（Compose） | iPad 和平板适配 |
| **数据** | 全部本地存储，离线可用，不需要账号 | 可选账号 + 云同步 |

## 路线图

```
v0.1  MVP          简繁中 + 英语，三段旅程的核心闭环
v0.2  语言工具      长按查词、词汇本、陷阱雷达、语言渐变
v0.3  好玩起来      小游戏题型、迷雾地图、茶杯收藏、分享卡片
v0.4  更多语言      乌尔都语、阿拉伯语（RTL）、印地语、乌克兰语
v0.5  考前冲刺      迷你模考、辅助模考、考前清单、考后流程
v1.0  正式发布      插画故事卡、专题收藏、听书模式、社区翻译
```

## 需要验证的关键假设

| 假设 | 怎么验证 | MVP 中的指标 |
|---|---|---|
| 母语对照能显著降低学习门槛 | 对比不同显示模式用户的完成率 | 第一站完成率 ≥ 70% |
| 故事化比题海更让人愿意学 | 看故事卡的完成率和停留时长 | 故事卡跳过率 < 20% |
| 每日茶歇能形成习惯 | 看连续学习天数分布 | 第 7 天留存 ≥ 40% |
| 语言渐变真的在发生 | 看翻译点开率随时间的变化 | 第 4 周翻译点开率比第 1 周下降 ≥ 50% |
| 准备度能预测真考结果 | 考后回访 | 准备度“绿色”用户真考通过率 ≥ 90% |

## 商业模式（初步想法）

原则：**核心学习免费，不用暗黑模式。**

- **免费**：全部学习之旅、每日茶歇、每周 1 次完整模考。
- **一次性买断（建议 £4.99–£7.99，不做订阅）**：无限模考、辅助模考、小游戏、听书模式、全部专题收藏。
  - 理由：用户考完就不用了，订阅会让人反感；对比一次考试费 £50，这个价格“帮我一次过”很划算。
- **不做**：广告（会破坏学习体验和信任感）。
- 可以考虑：给公益机构（难民援助组织）提供免费兑换码。

## 风险

| 风险 | 应对 |
|---|---|
| 手册改版、考试改革（政府 2025 年表示要更新考试内容） | 内容和 App 分离，内容包可以单独更新；所有知识点记录手册出处，改版时可以快速定位 |
| 题目版权 | 全部原创，不抄商业题库；见 [内容规范](../content/content-guidelines.md) |
| 翻译错误导致误导 | 翻译质量分级；考试以英文为准的提示；人工审校优先 |
| 被误认为官方 App | 明确标注“非官方”；不使用政府标志和 GOV.UK 字体、配色 |
| 用户过度依赖母语 | 语言渐变线 + 考场模式全英文 |
